# 修复内置浏览器控制栏被网页遮挡

## 问题与修复

部分手机打开内置浏览器后，仅能看到顶部标题和下方空页面提示，地址栏、打开按钮以及「允许 AI 操作此浏览器」开关不可见。控件仍存在于 Android UI 树中，点击原本的位置也能改变开关状态，因此仅检查 UI 树无法发现此问题。

网页区域使用原生 WebView 与 Compose AndroidView，外层容器没有限制绘制范围。为网页区域添加 `clipToBounds()`，让网页在自己的布局区域内绘制，避免覆盖上方控制栏。保留硬件渲染及现有会话、权限、下载和图片回传逻辑。

版本为 `2.5.5-miku.20261001.9-browser-controls`，versionCode 为 `192`，沿用包名和签名，支持覆盖安装。

## 验证

修复前已在 OPPO PLJ110 / Android 17 上复现：地址栏打开按钮和 AI 开关的截图区域均为纯白，但 UI 树包含控件，开关可响应点击。

最终优化 APK 已覆盖安装并通过以下手机验收：

- 地址栏打开按钮与 AI 开关在实际截图中可见，修复前的同一区域均为纯白。
- 通过手动点击关闭、开启 AI 开关，实际状态与显示一致。
- 手动输入 `https://example.com` 并打开，网页加载成功且不遮挡控制栏。
- 返回聊天再进入浏览器，控制栏仍可见。
- 关闭会话后 AI 权限重置，重新进入仍能看见并使用控制栏。
- 手机安装版本与最终 APK 的 SHA-256 一致，首次安装时间保持不变。
