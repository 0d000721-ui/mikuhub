# MikuHub

MikuHub 是基於 **[RikkaHub](https://github.com/rikkahub/rikkahub)** 原始碼定製的 Android AI 助手，由獨立維護者開發，感謝上游作者及貢獻者。

新增初音青主題與圖示、Agent 指令確認與提問卡片、模型旁的上下文和下載狀態、真實下載、可由 AI 操作的內建瀏覽器，以及 Shizuku / Root 設備工具與單檔 APK 靜默安裝。
